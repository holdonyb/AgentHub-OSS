Self-hosted AI Agent Control Plane

AgentHub

多设备、多电脑、多 Agent Runtime 的统一控制平面。把 server 跑在本机或 VM 上，通过 Tailscale private mode 或 HTTPS public relay，统一控制 Codex、Claude、Kimi、OpenCode。

它解决什么

AgentHub 不是托管 SaaS，也不是任意远程 shell。agent 继续运行在你的机器上，使用你的文件、工具和运行环境；AgentHub 负责会话收件箱、控制界面、worker 接入和审计记录。

统一会话收件箱

把本机和远程机器上的 Codex、Claude、Kimi、OpenCode 会话放到一个入口里。

多机器控制

Windows 和 Linux worker 都能接入，任务会被路由到对应机器执行。

手机可控

Android 可以直接处理审批、发回复、查看 session 和 worker 状态。

私有优先

优先走 Tailscale private mode；需要公网入口时，再单独挂 HTTPS public relay。

两种入口，并行成立

Tailscale private mode 和 HTTPS public relay 不是二选一。你可以只走私网，也可以只暴露 Web/API 入口，同时让 worker 继续通过私网或出站连接通信。

先跑起来，再考虑规模化

对个人和小团队来说，最实用的起点是把 server 跑在本地笔记本、工作站或一台小 VM 上。当前 release 已经覆盖 Web、Android、Windows Desktop、Windows/Linux worker。

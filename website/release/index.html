Public Release Notes

AgentHub 当前稳定版

AgentHub 保留 Session 控制台并加入 Workbench，统一发布 Web、两条 Android 渠道、Windows / macOS Desktop，以及 Windows / Linux / macOS worker。当前官网文案默认跟随 GitHub latest release。

下载当前版本 安装模式选择页 分享文案 GitHub Release

这个版本交付了什么

三种 server 安装路径

Local / Docker / VM 三条路径都已经有真实 smoke，不再只是脚本和文档存在。

多端入口

Web、Android、Windows / macOS Desktop 都能接入同一个 self-host server，worker 继续跑在你自己的机器上。

公开下载面

官网已经有自己的 `/download/` 和 `/install/` 页面，不再只是把人直接甩到 GitHub。

worker 安装收敛

优先走 `npx agenthub-worker`，手工 bundle 路径继续保留，Windows / Linux / macOS 都覆盖。

当前 release 资产

这里保留稳定下载名和用途说明。Android 与 worker 资产使用 latest release 的稳定文件名；桌面端资产文件名带版本号，所以统一跳 GitHub Release 页面。校验请以 latest release 的 SHA256SUMS 为准。

资产 用途 SHA256
agenthub-android-release.apk WebView 覆盖更新（xin.ifix.agenthub） SHA256SUMS
agenthub-native-android-release.apk 原生 Workbench（dev.myagenthub.mobile），可与当前版共存 SHA256SUMS
AgentHub-<version>-x64.exe Windows Desktop SHA256SUMS
agenthub-worker-windows.zip Windows worker bundle SHA256SUMS
agenthub-worker-linux.tar.gz Linux worker bundle SHA256SUMS
SHA256SUMS 全量校验文件 以 Release 中下载的文本内容为准

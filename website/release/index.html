Public Release Notes

AgentHub v0.1.1

这是第一轮公开可用版本。重点不是再加一层概念，而是把 self-host 控制面、worker 接入、Android、Windows Desktop、Docker 和 VM 这几条真实链路收口到能下载、能安装、能 smoke、能复现。

下载当前版本 安装模式选择页 分享文案 GitHub Release

这个版本交付了什么

三种 server 安装路径

Local / Docker / VM 三条路径都已经有真实 smoke，不再只是脚本和文档存在。

多端入口

Web、Android APK、Windows Desktop 都能接入同一个 self-host server，worker 继续跑在你自己的机器上。

公开下载面

官网已经有自己的 `/download/` 和 `/install/` 页面，不再只是把人直接甩到 GitHub。

worker 安装收敛

优先走 `npx agenthub-worker`，手工 bundle 路径继续保留，Windows / Linux 都覆盖。

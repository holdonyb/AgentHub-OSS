桌面客户端

用于 Windows 原生桌面接入。同样首启先填写 server URL，再进入登录页。Windows 安装包文件名随版本变化，所以这里直接跳到最新 Release 页面。

装 worker

如果 server 已经起来，优先用 `agenthub-worker`。如果你更喜欢手工安装，也可以直接下载 bundle。

Recommended

npx / npm 安装

公开安装入口已经收敛成 unscoped 包名，后续文档和 runbook 都默认这条路径。

npx agenthub-worker doctor
npx agenthub-worker install --api-url https://agenthub.example.com --enrollment-token ahe_worker_enroll_xxx --platform windows --worker-id workstation-01 --workspace-root E:/Work

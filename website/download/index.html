Release Downloads

先拿客户端，再接自己的 server

这里提供公开 release 的稳定入口。Android、Windows Desktop、Windows/Linux worker bundle 和 SHA256 校验文件都从这里分发；真正的登录和数据仍然走你自己 self-host 的 AgentHub server。

先选安装模式 查看 GitHub Release 返回首页

下载 release 资产

这些链接都固定指向最新 release 的同名文件，适合放在官网、群聊、文档和演示视频里直接引用。

Android

APK 客户端

用于手机上查看 session、发回复、处理审批、收通知。首启先填写你自己的 AgentHub server URL。

文件：agenthub-android-release.apk
下载 APK
Windows Desktop

桌面客户端

用于 Windows 原生桌面接入。同样首启先填写 server URL，再进入登录页。由于 EXE 文件名带版本号，这里稳定跳到最新 release 页面。

入口：latest release page
打开 release 页面

装 worker

如果 server 已经起来，优先用 `agenthub-worker`。如果你更喜欢手工安装，也可以直接下载 bundle。

Recommended

npx / npm 安装

公开安装入口已经收敛成 unscoped 包名，后续文档和 runbook 都默认这条路径。

npx agenthub-worker doctor
npx agenthub-worker install --api-url https://agenthub.example.com --enrollment-token ahe_worker_enroll_xxx --platform windows --worker-id workstation-01 --workspace-root E:/Work
Manual bundles

Windows / Linux worker bundle

适合你要把 worker 资产单独留档、手工分发，或者在没有 npm 的环境里解压安装。

下载 Windows worker bundle 下载 Linux worker bundle 查看 worker bundle manifest

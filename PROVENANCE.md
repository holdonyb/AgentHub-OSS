# Provenance

AgentHub is inspired by the product direction of multi-provider coding-agent control tools, including Paseo and opencode-style mobile clients.

The implementation in this repository is intended to be clean-room code:

- no source files are copied from those projects
- UI copy and documentation are written for AgentHub
- integrations are implemented against public provider/runtime behavior and local AgentHub protocols

If a contribution is based on another project's source code, it must be disclosed before review and must be license-compatible with this repository.

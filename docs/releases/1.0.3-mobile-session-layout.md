# AgentHub 1.0.3 Mobile Session Layout

## Scope

AgentHub 1.0.3 is a focused mobile usability release. It preserves the session, task, file, worker, authentication, and notification protocols from 1.0.2 while making the native Android console and compatibility WebView materially denser and easier to operate on a phone.

## Native Android

- The session inbox uses a compact header with refresh, search, and create actions instead of stacking a large title, create button, search field, tabs, filters, and batch controls above the first session.
- Search appears only when requested. Backend, status, and worker filtering lives in a bottom sheet, and batch selection appears only when active.
- Session cards keep the actionable metadata while limiting summaries to two lines, allowing more sessions to remain visible in the first viewport.
- Session detail keeps reply modes and quick replies behind one expandable row. The collapsed composer leaves the timeline as the primary surface.
- Status labels are localized and implementation-level values such as `completed` are not rendered to users.

## Compatibility WebView

- The mobile composer reserves less vertical space and collapses secondary controls while the text field is focused.
- Timeline filters scroll horizontally and no longer remain as a second sticky header over the conversation.
- Existing desktop behavior and the full control surface remain unchanged.

# AgentHub 1.0.5 Native Regression Recovery

## Scope

AgentHub 1.0.5 replaces an invalid local 1.0.4 Android candidate that was built from an obsolete worktree. The official release is built from the current mainline and retains the complete React Native console introduced in 1.0.2 and refined in 1.0.3.

## Restored Native Surface

- Session create, search, inbox/archive tabs, backend/status/worker filters, and batch actions.
- Full session timeline with localized states, Markdown rendering, full-text reading, copy, attachments, approvals, direct/plan replies, and session actions.
- Scoped remote workspace browsing, preview, editing, upload, rename, and directory creation.
- Task review, worker diagnostics, notification inbox, appearance settings, update checks, and safe server switching.
- UTC-safe relative times and sorting by actual recent session activity.

## Layout Fix

The session timeline now measures the visible reply composer and reserves the same amount of bottom scroll clearance. The latest message can move completely above the composer even when reply modes, quick actions, attachments, or status details expand it.

## Release Safety

The invalid 1.0.4 candidate was never tagged as an official release. Version 1.0.5 raises the native Android version code to 5 and the compatibility Android version code to 22 so both clients can upgrade through the signed release path.

## Verification

The release gate includes React Native tests and type checking, compatibility Android tests, release-version alignment, signed Android builds, APK manifest inspection, and a production download checksum check.

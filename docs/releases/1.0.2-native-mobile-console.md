# AgentHub 1.0.2 Native Mobile Console

## Scope

AgentHub 1.0.2 completes the first production-ready React Native control console for Android while retaining the compatibility WebView client. The release focuses on phone-first session control, remote workspace files, task review, worker diagnostics, notifications, and account settings.

## User-visible changes

- Session inbox search, backend/status/worker filters, recent-activity ordering, archive, batch archive, foreground refresh, and background polling.
- Session timeline paging and search, Markdown rendering, full-message reading/copying, collapsed tool output, attachments, file handoff, direct/plan replies, quick replies, voice input, structured choices, approvals, fork, BTW, rename, archive, and termination.
- Task search, creation, dispatch, review, accept/reject/rework, archive/restore, and artifact-to-workspace navigation.
- Remote workspace switching, directory and workspace search, recent files, Markdown/raw preview, bounded text editing, image/audio/video preview, create, mkdir, rename, upload, and download.
- Worker heartbeat, capabilities, workspace roots, provider readiness, and provider login/logout controls.
- Notification inbox with read/dismiss behavior, theme and composer preferences, release metadata, update link, and safe server switching.

## Freshness fixes

Two independent defects caused stale-looking or missing sessions:

1. SQLite timestamps are stored as naive UTC, but the native client parsed API values without an offset as device-local time. The client now normalizes timezone-less API datetimes to UTC before relative-time rendering.
2. The installed worker used one shared discovery limit across every backend. A large Codex history could consume the limit before Claude or Kimi files were examined. Discovery now applies the configured limit independently to each backend.

Session cards use the newer of `last_activity_at` and `updated_at`, then sort locally by that effective activity timestamp. A worker update is required before the per-backend discovery fix is active on an installed machine.

## Release boundaries

- Android is the supported native mobile artifact in this release.
- iOS and macOS native artifacts remain community-contribution targets.
- Compatibility WebView APK remains available during migration.
- Physical-device push delivery and live write mutations require the operator's authenticated server/device and remain part of post-deploy smoke rather than public CI.
